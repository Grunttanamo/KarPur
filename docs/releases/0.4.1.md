# KarPur Launcher 0.4.1

Draft release notes for the upstream pull request. The original maintainer's discontinuation notice remains in the [README](../../README.md); a 0.4.1 release depends on upstream review and acceptance.

## Changes in 0.4.1

- **RDNA 3 transform-feedback synchronization:** add a full barrier after each captured draw by default on RDNA 3 devices. Set `TOTK_XFB_SYNC=0` to disable it, or `TOTK_XFB_SYNC=1` to enable it on other devices. This targets reported device-loss issues during character creation on AMD RDNA 3 GPUs; it is a mitigation, not a confirmed fix, and still needs hardware validation.
- Updated the Windows and Linux launcher version to 0.4.1. The Linux AppImage is named `KarPur-Linux-Launcher-0.4.1.AppImage`.
- Added RecompLauncher setup, game settings, save/log locations and direct game start. Its guided setup accepts an XCI base game; use KarPur's own launcher for an NSP base game that needs firmware. The Windows ZIP and Linux AppImage packages include `recomplauncher.json`.

## Limitations

Linux and Steam Deck support remain experimental. Packaging self-checks do not replace a fresh installation and gameplay check on a Steam Deck or AMD RDNA 3 hardware. The launchers contain no game files, dumps or keys.
