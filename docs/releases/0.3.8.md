KarPur Launcher **0.3.8** fixes a build failure when updating an existing installation.

## Fixed in 0.3.8

- **Builds after an update could fail with undefined `res_shadow_*` symbols.** Thanks to @alcantarilla22 for reporting this in [issue #66](https://github.com/Grunttanamo/KarPur/issues/66). The launcher unpacked source files with older archive timestamps, so Ninja could incorrectly reuse compiled files from an earlier version. Updated files now receive current timestamps; on a launcher-version change, unchanged project files are also refreshed to recover installations already affected by this problem. Subsequent builds of the same version remain incremental.
- **Link failures now point to the actual linker errors**, instead of always suggesting that a running game was locking the executable.
- Added an automated regression test using the actual launcher unpacker and a synthetic archive. All seven launcher checks pass, including nine unpacking assertions. The update was also tested successfully on an existing installation.

**If you encountered #66:** update to Launcher 0.3.8 and build again. You do not need to delete your installation or extract your game again.

## Included from 0.3.7

These changes were already included in 0.3.7 and are retained in 0.3.8:

- Fixed the launcher error dialog when switching keyboard layouts while a text field or build log has focus (`CultureNotFoundException` / globalization-invariant mode).
- Fixed the crash when opening the map with shadow quality x4 ([#61](https://github.com/Grunttanamo/KarPur/issues/61)). Both shadow render targets now preserve the game's original graphics-memory budget.
- Fixed recovery after an interrupted compiler/toolchain download ([#62](https://github.com/Grunttanamo/KarPur/issues/62)). The build now checks the complete package list and continues an incomplete setup.
- Fixed builds in installation folders containing characters outside the system codepage ([#65](https://github.com/Grunttanamo/KarPur/issues/65)).
- Improved failed-build reports so they show the actual failure and nearby lines instead of unrelated warnings at the end of the log.
- Retained everything from 0.3.5: shadow quality up to x4 and Disabled, no version exclusives, no trade evolutions, stutter reduction, the volume fix and `.nsp` base-game support.
- Added the optional AMD character-creation diagnostic switch `TOTK_XFB_SYNC=1` ([#18](https://github.com/Grunttanamo/KarPur/issues/18)); it is off by default and slower when enabled. This is a diagnostic option, not a confirmed AMD crash fix.
- Added six checks for the launcher's build path and a release checklist for contributors.

KarPur builds the game from your own dump. No game data is included.
